# A股 ETF 份额变化监控 —— Python 运行环境依赖
# ===============================================================
#
# 依赖数量：0（仅使用 Python 标准库，无任何第三方运行时依赖）
#
# 因此本文件不声明任何安装包，执行下面的命令是空操作（安全、秒完成）：
#
#     pip install -r requirements.txt
#
# 之所以仍然提供本文件，是为了：
#   1) 让 CI / 部署脚本里的 `pip install -r requirements.txt` 有文件可用；
#   2) 显式声明「本项目刻意不引入第三方依赖」这一设计约束，避免后人误加。
#
# ---------------------------------------------------------------
# 环境要求
# ---------------------------------------------------------------
# Python >= 3.8
#
#   * 实际使用到的最高语法特性为 f-string（3.6+）与 dict 保序（3.7+），
#     未使用海象运算符(:=)、match 语句、内置泛型注解、removeprefix 等 3.8+ 语法；
#     故 3.8 是宽松的安全下限（3.6/3.7 已 EOL，不予支持）。
#   * 已在 CPython 3.13、3.14 上实测运行通过（`python main.py report`）。
#   * 无需虚拟环境，亦无需 C 编译工具链。
#
# ---------------------------------------------------------------
# 用到的标准库模块清单（仅供代码审查参考，无需安装）
# ---------------------------------------------------------------
#   urllib.request / urllib.parse   HTTP 请求与参数编码（全部数据源接口）
#   zipfile / xml.etree.ElementTree 解析交易所导出的 xlsx（inlineStr 单元格，
#                                   故不需要 openpyxl / pandas）
#   sqlite3                         本地增量存储（data/etf_shares.db，WAL 模式）
#   concurrent.futures / threading  多线程并发抓取与每线程独立连接
#   json                            指数字典缓存、报告内嵌明细载荷
#   re / html / difflib             名称归一化、HTML 转义、指数名称模糊匹配
#   datetime / time                 交易日回推、窗口基期选取、限速
#   os / sys / io / random          路径、命令行参数、内存字节流、请求随机数
#
# ---------------------------------------------------------------
# 开发/验证用工具（非运行时依赖，且不属于 Python 生态）
# ---------------------------------------------------------------
#   报告的浏览器端交互验证使用 Node.js + playwright-core（npm 包），
#   直接驱动本机已缓存的 Chromium，不接入本工程的运行流程。
#
# ---------------------------------------------------------------
# 运行方式
# ---------------------------------------------------------------
#     python main.py            # 更新数据 + 生成报告
#     python main.py update     # 仅更新数据（本地缺失时自动去官网补全）
#     python main.py index      # 仅修复跟踪指数映射（补缺失 + 纠正错误）
#     python main.py report     # 仅用本地数据重新生成 HTML 报告
#
# 报告输出：output/etf_index_share_report.html
